Connecting Programs to Databases

This topic is where SDD and DDD meet — the integration at the heart of most Advanced Higher projects. You must be able to describe, exemplify and implement code that can:

  • open and close a connection to a database server;
  • execute an SQL query from within a program;
  • format the query results for display.
ℹ️
The question paper only uses SQA reference language, so language-specific connection code (Python's mysql-connector, Java's JDBC, VB's OleDb) will not appear in the exam — but you need it for your project, and you may be asked to describe the steps or design them in pseudocode.

Key Terms

Database Server
The software (e.g. MySQL) that stores the database and answers SQL requests from programs.
Connection
The live link between your program and the database server, opened with credentials (host, user, password, database) and closed when finished.
Cursor
The object a program uses to execute SQL statements and step through the results.
Query Results
The rows returned by a SELECT — retrieved into a program structure (e.g. a list of tuples) and then formatted for output.

The Four Steps

Whatever the language, the pattern is identical — learn it as a sequence you can write in pseudocode:

Pseudocode — the universal pattern
1. assign server connection variables (host, user, password, database)
2. open connection to the database server
3. execute SQL query
4. process the results
   4.1 if rows returned, fetch each row in turn
   4.2 format and display each row
5. close connection to the database server

Wrapping the connection in a try structure keeps the program robust: if the connection fails, an error message is displayed instead of the program crashing — a point worth making in your project evaluation.

Python — connect, query, display, close
import mysql.connector

try:
    conn = mysql.connector.connect(
        host="localhost",
        user="root",
        password="",
        database="StudentData")
except:
    print("Could not connect to database")
else:
    cursor = conn.cursor()
    cursor.execute("SELECT * FROM Student")
    results = cursor.fetchall()
    for row in results:
        print(str(row[0]) + " - " + row[1] + " " + row[2])
    conn.close()

Line by line: the cursor object executes the SQL; fetchall() returns the results as a list of tuples; the loop formats each tuple into readable output; and the connection is closed at the end of the script.
